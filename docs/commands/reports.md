# reports

Manage YAML report files generated by wildintel-tools commands. Reports are stored in the default reports directory (`~/.wildintel-tools/reports/`).

---

## list

Show a summary of all report files found in the reports directory.

```bash
wildintel reports list
```

---

## info

Load and display the contents of a specific report file. If no filename is given, the most recent report is shown.

```bash
wildintel reports info [FILENAME]
```

| Argument | Type | Default | Description |
|---|---|---|---|
| `FILENAME` | str | `None` | Name of the YAML report file to display. Defaults to the most recent report. |

**Example**

```bash
# Show the latest report
wildintel reports info

# Show a specific report
wildintel reports info report_20240501_123456.yaml
```

---

## archive

Rename report files older than a given number of days by prefixing them with a dot (hidden). This keeps the directory tidy without permanently deleting reports.

```bash
wildintel reports archive [DAYS]
```

| Argument | Type | Default | Description |
|---|---|---|---|
| `DAYS` | int | `60` | Age threshold in days. Files older than this will be archived. |

**Example**

```bash
# Archive reports older than 60 days
wildintel reports archive

# Archive reports older than 30 days
wildintel reports archive 30
```

---

## remove

Permanently delete previously archived (hidden) report files. The command lists the files that will be deleted and asks for confirmation before proceeding.

```bash
wildintel reports remove
```

!!! warning
    This operation is irreversible. Confirm carefully before proceeding.
